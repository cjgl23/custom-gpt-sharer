# Security Policy

## Supported versions

Security fixes are provided for the latest version on the default branch (`main`).

## Reporting a vulnerability

Do **not** disclose security vulnerabilities, credentials, session cookies, or reproduction payloads in public issues or pull requests.

Use **Security → Report a vulnerability** on this GitHub repository when private vulnerability reporting is available. Otherwise, open a public issue **without exploit details**, asking the maintainer to arrange a private communication channel.

Include affected versions, impact, and reproducible steps only through a private channel. Please allow time for investigation before public disclosure.
