# Project Brief

## Project Name
GPT Share Bot

## Overview
This utility takes a list of emails from a text file and the name of a custom GPT in ChatGPT as inputs. The utility will then copy-paste the emails one at a time to the share box of the custom GPT to enable sharing of the custom GPT to the individuals in bulk.

## Core Requirements
- Read email addresses from a text file
- Navigate to custom GPT sharing interface
- Automate email entry and sharing process
- Handle bulk sharing operations
- Follow corporate restrictions and constraints

## Goals
### Primary Goals
- Enable efficient bulk sharing of custom GPTs
- Automate repetitive sharing tasks
- Maintain security and privacy compliance

### Secondary Goals
- Provide user-friendly interface
- Handle error scenarios gracefully
- Ensure reliable operation

## Scope
### In Scope
- Reading email lists from text files
- Browser automation for GPT sharing
- Error handling and logging
- Corporate policy compliance

### Out of Scope
- Creating or managing GPTs
- Email validation beyond basic format checking
- Advanced user interface (CLI only)
- Integration with external email systems

## Success Criteria
- Successfully shares GPT to all emails in input file
- Handles errors gracefully without stopping the process
- Complies with all corporate restrictions
- Provides clear feedback on sharing progress
